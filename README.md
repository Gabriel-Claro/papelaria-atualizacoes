# Papelaria Mitsutani · Atualizações para Windows

Canal oficial de avisos de versão do Sistema Papelaria Mitsutani.

## Como funciona

Quando uma entrega é aprovada, o responsável publica um manifesto com a versão, o nome do pacote e seu hash SHA-256. O sistema verifica a assinatura digital antes de exibir o aviso na loja.

## Decisão de instalação

O responsável escolhe quando atualizar, confere o hash do ZIP e prepara a nova versão em uma pasta separada. O banco, os backups e as configurações ficam no ambiente da loja.
